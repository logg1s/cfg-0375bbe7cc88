## 0.4.3 - 2026-05-31

### Added

- Installer now writes `.agentkit/manifest.json` with hashes for Agent Kit-owned files.
- Installer/self-update now refuses to overwrite manifest-owned files that were edited locally.
- `update-check` now prints a public changelog URL and supports `--show-changelog`.
- Documentation now recommends `update-check --show-changelog` before `self-update`.

### Fixed

- Reduced risk that self-update overwrites user-edited installed kit files without an explicit conflict.
