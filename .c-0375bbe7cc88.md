## 0.4.6 - 2026-05-31

### Added

- Added `frontend-gate` for landing/static UI tasks. It checks required section IDs, internal anchors, linked local assets, basic content/responsive/visual signals, and optional Chrome/Edge desktop/mobile screenshots.
- Added `task-contract` to extract/check acceptance criteria, constraints, verifier plans, and frontend-specific contract hints before implementation.
- Autopilot now adds `frontend-gate` for frontend, landing page, website, UI, layout, responsive, and visual tasks.
- Added workflow budget selection (`light`, `standard`, `deep`) so Agent Kit does not over-process low-risk tasks.
- Added `frontend-reviewer` and `browser-qa` subagent routing for visual/UI work.
- Added harness evaluation notes covering paired baseline-vs-kit trials, ablations, hidden validators, and overhead metrics.
- Added regression tests for missing task contracts, frontend contract sections, and broken anchor targets.

### Changed

- Workflow guidance now separates process evidence from task success evidence and requires task-contract alignment before final delivery.
- Frontend/web-app prompts no longer route to research merely because they contain the word "web".
