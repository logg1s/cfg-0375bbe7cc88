## 0.4.8 - 2026-06-01

### Added

- Added `prompt-repair` for terse or messy task normalization.
- Added `memory-audit` for stale, low-confidence, and unsourced memory checks.
- Added Agent Kit effectiveness review docs and project operations runbooks.
- Added baseline-first artifact workflow with post-first-pass sidecar review when it reduces risk.
- Added frontend gate checks for Vietnamese/accented text integrity and mobile heading word-break issues.

### Changed

- Memory search now reranks by project match, memory kind, confidence, source/freshness, and expiry.
- Session-start hook context is compact; detailed capability/model maps stay on demand.
- Subagent routing now uses general-purpose roles such as `reviewer`, `qa-runner`, `test-strategist`, `architect`, and `security-reviewer`.
- Frontend remains covered by `frontend-gate` as a validator, not as a special subagent architecture path.
- Windows hook commands quote PowerShell payloads safely.
