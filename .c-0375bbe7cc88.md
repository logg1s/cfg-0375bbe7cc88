## 0.4.7 - 2026-05-31

### Added

- Added `harness-check` to validate paired benchmark/eval manifests before running baseline-vs-kit trials.
- Added `subagent-brief` to generate self-contained operating packets for delegated agents, including relevant skills, writer scope, gates, and output contracts.
- Added compact subagent briefs for implementation workers so main can pass skills/gates without slowing the worker down.
- Added research/content rules to subagent briefs for source-backed copy and internet image attribution.
- Harness manifests now require explicit prompt, acceptance criteria, visible tests, hidden validator, expected artifacts, budget, paired variants, and failure taxonomy.

### Changed

- Harness docs now recommend validating eval manifests before running paired trials.
- `frontend-gate` now treats explicit `--required-section` values as the source of truth instead of adding inferred sections from generic task text.
- Subagent routing docs now require main to pass the relevant workflow/skill brief explicitly, especially for frontend/browser QA work.
- Frontend subagent briefs now warn against unrequested decorative eyebrows/badges/pills and extra above-the-fold copy.
- Research subagent briefs now require source URLs, image credits, and explicit not-verified items.
